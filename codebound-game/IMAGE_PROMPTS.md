# Image Prompts - CodeBound Game Assets

Use these prompts in DALL-E, Ideogram, Midjourney, or similar to generate sprites/UI art. Export as PNG (transparent background where needed) and import into Unity (Assets/Sprites/ or Assets/UI/).

---

## 1. Character (player)

- **Prompt:** "2D game character sprite, top-down or side-view, programmer/student style, simple clean shapes, cyan and white colors, single frame, transparent background, 256x256 pixels, no text."
- **Alternative:** "Pixel art character sprite sheet, 32x32, coding theme, cyan blue color, idle pose, transparent background."

---

## 2. Paper (challenge / hint)

- **Prompt:** "2D game asset, scroll or paper document, blue tint, simple flat design, transparent background, 128x128, no text."
- **Alternative:** "Pixel art paper or scroll item, blue, 64x64, top-down view, clean edges."

---

## 3. PC / Terminal station

- **Prompt:** "2D game asset, desktop computer or terminal station, simple geometric, white and gray, front view, 128x128, transparent background, no text."
- **Alternative:** "Pixel art computer desk with monitor, 64x64, minimal style, white and dark gray."

---

## 4. Door (locked / unlockable)

- **Prompt:** "2D game door sprite, red or orange, simple rectangle with door frame, side view, 64x128, transparent background, no text."
- **Alternative:** "Pixel art door, locked style, red, 32x64, single frame."

---

## 5. Token / collectible

- **Prompt:** "2D game collectible coin or token, golden yellow, round, simple shiny style, 64x64, transparent background."
- **Alternative:** "Pixel art gold token, 32x32, top-down, glowing edge."

---

## 6. Portal / level exit

- **Prompt:** "2D game portal or vortex, cyan and blue gradient, circular, magical effect, 128x128, transparent background."
- **Alternative:** "Pixel art portal entrance, 64x64, cyan blue, glowing, simple."

---

## 7. UI - Code terminal panel

- **Prompt:** "2D UI panel, dark gray or black, code editor style, rectangular, subtle border, 512x384, transparent or dark background, no text."
- **Alternative:** "Minimal UI panel, dark theme, rounded corners, 1024x768, for game code input."

---

## 8. UI - Buttons (Run, Clear, Hint, Exit)

- **Prompt:** "2D game button, rectangular, cyan or blue, simple flat design, 128x48, transparent background, no text."
- **Alternative:** "Pixel art button, 64x32, blue, raised style, no text."

---

## 9. Platform / ground tile

- **Prompt:** "2D platform game tile, gray stone or metal, single tile, 64x64, seamless edge, top-down or side view, no text."
- **Alternative:** "Pixel art platform block, gray, 32x32, simple."

---

## 10. HUD - Token icon

- **Prompt:** "2D game HUD icon, small gold token or star, 32x32, transparent background, no text."
- **Alternative:** "Minimal icon, golden circle, 64x64, flat design."

---

## Tips for Unity

- Import as Sprite (2D and UI) and set Filter Mode (Point for pixel art, Bilinear for smooth).
- Use Sprite Editor to slice if you generate sprite sheets.
- Assign to Sprite Renderer (world) or Image (UI) in your existing prefabs/GameObjects.
