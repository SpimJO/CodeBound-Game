---

## 📝 **USAGE:**

1. **Generate sprites from Bing:**
   - `09_background_cyan.txt` → Cyan Lab
   - `32_bg_purple_datacenter.txt` → Purple Data Center
   - `33_bg_orange_firewall.txt` → Orange Firewall
   - `34_bg_red_core.txt` → Red Core

2. **Save to theme folders:**
   ```
   Download from Bing → Rename → Save to correct theme folder
   ```

3. **Apply in Unity:**
   ```
   Drag background sprite onto Background GameObject
   Level 1-25: Use Cyan
   Level 26: Switch to Purple
   Level 51: Switch to Orange
   Level 76: Switch to Red
   ```
