# CodeBound Character Designs

## Complete Character Skin Collection

All character skins for the CodeBound game with detailed design specifications and AI generation prompts.

## Design Philosophy

**Style**: Pixel art / 2D cartoon style
**Target**: Teen-friendly, colorful, appealing
**Animation**: Smooth, expressive movements
**Size**: 64x64 pixels per character (32x32 for mobile optimization)
**Color Palette**: Vibrant, high contrast for visibility

## Animation Frame Breakdown

### Standard Animation Set (All Skins)

#### Idle Animation (4-6 frames, 0.5s duration)
- Frame 1-2: Neutral pose
- Frame 3-4: Slight bob up
- Frame 5-6: Bob down, return to neutral

#### Walk Animation (8 frames, 0.8s duration)
- Frame 1: Contact left
- Frame 2: Down position
- Frame 3: Passing position
- Frame 4: Up position
- Frame 5: Contact right
- Frame 6: Down position
- Frame 7: Passing position
- Frame 8: Up position

#### Run Animation (8 frames, 0.6s duration)
- Similar to walk but faster, more dynamic
- Lean forward more
- Arms pump harder

#### Jump Animation (4 frames)
- Frame 1: Crouch preparation
- Frame 2: Launch (legs extended)
- Frame 3: Peak (arms up)
- Frame 4: Arc (body turning forward)

#### Fall Animation (3 frames)
- Frame 1: Descent start
- Frame 2: Accelerating (arms out)
- Frame 3: Fast fall (streamlined)

#### Land Animation (3 frames)
- Frame 1: Impact crouch
- Frame 2: Absorb impact
- Frame 3: Recovery stand

#### Death Animation (5-6 frames)
- Frame 1: Hit reaction
- Frame 2-3: Stumble/fall
- Frame 4-5: On ground
- Frame 6: Fade/dissolve

## Technical Specifications

### Sprite Sheet Layout
```
[Idle x6][Walk x8][Run x8][Jump x4][Fall x3][Land x3][Death x6]
Total frames per skin: ~38 frames
```

### File Naming Convention
```
character_[skinId]_[animation]_[frame].png

Examples:
character_default_idle_01.png
character_cyber_walk_05.png
character_ninja_jump_03.png
```

### Unity Import Settings
- **Texture Type**: Sprite (2D and UI)
- **Sprite Mode**: Multiple
- **Pixels Per Unit**: 64
- **Filter Mode**: Point (no filter) for pixel art
- **Compression**: None
- **Max Size**: 512 or 1024

### Animation Controller Setup
```
Create one Animator Controller per skin:
- DefaultAnimator.controller
- CyberAnimator.controller
- NinjaAnimator.controller
etc.

Animation clips:
- Idle.anim
- Walk.anim
- Run.anim
- Jump.anim
- Fall.anim
- Land.anim
- Death.anim

Parameters:
- Speed (float) - walking speed
- IsGrounded (bool)
- IsJumping (bool)
- IsDead (bool)
```
