## 🔄 **REPLACE IN UNITY:**

### **Fast Method:**
1. Open Unity project
2. Go to: `Assets/Sprites/Characters/Default/`
3. **Delete:** `default_idle.png` (placeholder)
4. **Drag:** Your new character.png here
5. **Rename** to: `default_idle.png`
6. Repeat for other sprites

**That's it!** Unity auto-updates everything! ✅

## 💡 **PRO TIPS:**

**Too slow?**
- Do character + platform only first
- Use placeholder squares for rest
- Replace later at your pace

**Bad results?**
- Generate 3-4 versions
- Pick best one
- Try "Alternative Prompt" from txt file

**Wrong size?**
- Use Paint/GIMP to resize
- Character: 32x32
- Platform: 32x32
- Door: 32x64
- PC: 64x64
- Portal: 64x64
- Token: 16x16
