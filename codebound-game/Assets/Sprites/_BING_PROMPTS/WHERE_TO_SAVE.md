## 📝 **STEP-BY-STEP WORKFLOW:**

### **After Each Bing Generation:**

**Step 1: Download**
- Bing shows your image
- Right-click → Save Image As...
- Save to Desktop temporarily

**Step 2: Process (Optional)**
- Open in Paint/GIMP
- Crop to correct size
- Remove background if needed
- Save as PNG

**Step 3: Rename**
- Check filename above (e.g., "default_idle.png")
- Rename your downloaded file

**Step 4: Move to Unity**
- Copy file
- Navigate to correct folder (see paths above)
- **Paste and REPLACE** if placeholder exists
- Unity auto-detects the new sprite!

---

## 🔄 **EASY METHOD (Drag & Drop):**

1. Generate sprite in Bing
2. Download to Desktop
3. Open Unity
4. Find correct folder in Project window:
   - Example: `Assets/Sprites/Characters/Default/`
5. **Drag file from Desktop into Unity folder**
6. Rename in Unity if needed
7. Done! ✅

## 🚨 **COMMON MISTAKES:**

❌ **Wrong folder:**
- Putting character in Platforms folder
- Fix: Move to correct location

❌ **Wrong filename:**
- "character.png" instead of "default_idle.png"
- Fix: Rename to exact name shown above

❌ **Wrong format:**
- JPG instead of PNG
- Fix: Re-save as PNG with transparency

❌ **Forgot to replace:**
- New file added but old one still there
- Fix: Delete old placeholder first
